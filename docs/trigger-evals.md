## Підсумок

- **Should-trigger (T1–T5): 5/5 — усі спрацювали.** Опис із самого початку добре покривав
  цільові сценарії (виклик n8n, колбек від n8n, «форма показує успіх, а воркфлоу не
  запустився» — рівно ситуація з Task 0).
- **Should-not-trigger (N1–N5): 3/5 правильно НЕ спрацювали (N2, N3, N4); 2/5 — хибне
  спрацювання (N1, N5).** В обох хибних випадках модель, отримавши доступ до скіла, сама
  коректно **не застосувала** контракт до відповіді (розпізнала, що задача не про Next.js↔n8n
  webhook-контракт) — тобто фінальний результат не постраждав, але сам факт завантаження
  контексту скіла на нерелевантний запит — зайвий шум і привід уточнити `description`.

## Що змінено в `description`

Було: загальний опис «Use when… форму/дію, що запускає зовнішній воркфлоу через вебхук» і
короткий список винятків («Не для: … коду для вузла Code в n8n, черг і фонових воркерів»).

Стало (`.claude/skills/integrating-n8n-webhooks/SKILL.md`):

1. Явно уточнено в першому ж реченні: контракт **саме для n8n**, «не з іншими сторонніми
  сервісами» — щоб опис не резонував із загальними «вебхук»/«колбек»-запитами про інші сервіси.
2. У «Тригери» до кожної фрази, де це мало сенс, додано слово «n8n» явно (`«запусти воркфлоу
  n8n»` замість просто `«запусти воркфлоу»`) — менше шансів зачепитися за загальний «запусти
  фоновий процес».
3. У «Не для» додано прямий, раніше відсутній пункт: **«інтеграцій з іншими сторонніми API чи
  платіжними системами (Stripe тощо) — у них свій контракт, цей не підходить як шаблон»** —
  саме цього пункту не вистачало для N5.
4. Посилення для N1: фраза «навіть якщо виглядає схоже» перед списком винятків — явний сигнал
  моделі не використовувати скіл «про всяк випадок» чи як довідку для дотичних, але не
  застосовних задач.

Довжина опису після правки: 826/1024 символів (у межах ліміту); `SKILL.md` — 129/500 рядків.
Повторний прогін N1/N5 із новим описом — не робився в межах цього бонусного завдання (за
браком часу); якщо після мерджу хибні спрацювання повторяться, це стане окремою знахідкою для
наступного рев'ю скіла.
