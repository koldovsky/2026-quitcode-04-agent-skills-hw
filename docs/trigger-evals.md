> Мета: перевірити не «спрацював один раз» (як у Task D, прогін B), а **межі** `description` —
> чи він спрацьовує на різноманітні реалістичні формулювання задачі, і чи **не** спрацьовує на
> суміжні, але чужі задачі (зокрема на явно винесені «поза межами» скіла).

**Інструмент:** Claude Code CLI, неінтерактивний режим:
```bash
claude -p "<запит>" --output-format stream-json --verbose \
  --allowedTools "Skill,Read,Grep,Glob" --disallowedTools "Edit,Write,NotebookEdit,Bash" \
  > run.jsonl
grep -o '"skill":"[^"]*"' run.jsonl
```
Кожен запит — окремий виклик (окрема, свіжа сесія без пам'яті про попередні). `--disallowedTools`
блокує реальні зміни файлів/команди, тож можна безпечно запускати прямо в робочому репозиторії.
Файли `run.jsonl` не комітяться (лишились у `/tmp`, не в репозиторії).
