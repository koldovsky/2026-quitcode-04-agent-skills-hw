# Відомі пастки й межі скіла

Повернутися до [SKILL.md](../SKILL.md).

## Пастки в документації й чужих скілах

- **Текст відповіді Immediately.** Документація n8n пише «Workflow got started», а код n8n повертає
  `{"message":"Workflow was started"}`. Тому відповідь оцінюємо лише за кодом статусу.
- **Header Auth — 403, не 401.** Офіційний пакет скілів n8n стверджує, що Header Auth відхиляє запит з 401;
  код вузла Webhook повертає **403** «Authorization data is wrong!». 401 — це Basic Auth і JWT.
- **Секрет Crypto.** Той самий пакет пише, що секрет вузла Crypto не прив'язується до credential. Для Crypto
  v2 це вже не так: Hmac Secret береться з Crypto credential.
- **Приклад вебхука в документації Next.js** передає токен у `?token=` GET-запиту й порівнює через `!==`.
  GET може кешуватися й потрапляти в журнали. У нас — токен у заголовку, підпис HMAC і `timingSafeEqual`.
- **Тестовий URL «працює».** `/webhook-test/` приймає запити лише 120 с після «Listen for test event»; потім
  404, а код, що не дивиться на відповідь, «успішно» губить заявки. У коді й `.env.example` — лише `/webhook`.
- **Повторна серіалізація тіла.** `JSON.stringify(JSON.parse(raw))` дає інші байти — підпис не зійдеться.

## Поза межами скіла

- побудова й зміна воркфлоу в редакторі n8n, експорт чи імпорт JSON воркфлоу;
- код для вузла Code в n8n;
- черги й фонові воркери — для наших обсягів вистачає `after()` і колбеків.
